# lab2---TUI
Лабораторная работа: TUI приложение на C++ (вариант В - Почтовый клиент)

## maills — читалка локальных почтовых ящиков (Maildir) для терминала

Консольный клиент по образцу mutt: без сети, только чтение локального Maildir. Письма разбираются
вручную (MIME, base64, quoted-printable, RFC 2047), перекодировка — через iconv. Заголовки писем
кэшируются в SQLite, поэтому повторный запуск мгновенный, а новые письма подгружаются в фоне.

## Сборка и запуск (Linux)

Нужны компилятор с C++20 (g++ ≥ 11 или clang ≥ 14), CMake ≥ 3.20 и две библиотеки разработки:

# Debian / Ubuntu
sudo apt install build-essential cmake libsqlite3-dev libncurses-dev

cmake -S . -B build && cmake --build build -j
./build/app/maills <путь к Maildir>        # например ~/Mail/INBOX
ctest --test-dir build --output-on-failure  # тесты

Попробовать на тестовом ящике (лучше на копии: при открытии письма имена файлов меняются — это и есть флаги Maildir):

cp -r tests/data/maildir /tmp/box && ./build/app/maills /tmp/box

Параметры:

| параметр | значение |
|---|---|
| `--db FILE` | файл индекса SQLite (по умолчанию `~/.cache/maills/<путь ящика>.sqlite`) |
| `--keys FILE` | конфиг клавиш (по умолчанию `~/.config/maills/keys.conf`) |
| `--refresh SEC` | автообновление каждые SEC секунд, `0` — только по клавише `R` (по умолчанию 60) |
| `--list` | один раз синхронизировать, напечатать список писем и выйти (без TUI) |
| `--type T` | тип хранилища (сейчас `maildir`) |

Сборка с санитайзерами: `cmake -S . -B build-asan -DMAIL_SANITIZE=ON && cmake --build build-asan && ctest --test-dir build-asan`.
Без ncurses собираются ядро и тесты, TUI пропускается (CMake напишет предупреждение).

## Клавиши по умолчанию

| клавиши | команда | действие |
|---|---|---|
| `↓` / `↑` | down / up | вниз / вверх (в письме — прокрутка) |
| `Space` `PgDn` / `b` `PgUp` | page-down / page-up | страница вниз / вверх |
| `g` `Home` / `G` `End` | top / bottom | в начало / в конец |
| `Enter` `l` `→` | open | открыть письмо (оно становится прочитанным) |
| `q` | back-or-quit | назад; из списка — выход |
| `Esc` `h` `←` | back | назад |
| `Q` | quit | выход |
| `?` `F1` | help | справка (строится из текущих привязок) |
| `R` | refresh | подгрузить новые письма |
| `f` | toggle-flagged | пометить / снять пометку (флаг `F`) |
| `m` | toggle-seen | прочитано / непрочитано (флаг `S`) |
| `1` `2` `3` | sort-date / sort-sender / sort-subject | сортировка по дате / отправителю / теме |
| `v` | reverse-sort | обратный порядок |
| `t` | toggle-threads | треды деревом / плоский список |
| `/` | search | поиск: `иван`, `from:alice`, `subject:отчёт`, `is:unread`, `is:flagged` |
| `c` | clear-filter | сбросить поиск |
| `p` | toggle-parts | в письме: дерево частей ↔ текст |
| `s` | save-attachment | сохранить вложение (часть под курсором) в файл |
| `w` | save-text | сохранить текст письма в файл |
| `e` | export-eml | экспортировать письмо целиком в `.eml` |

Стрелки в письме: `↑` `↓` прокручивают текст (в дереве частей — выбирают часть), `←` закрывает письмо и возвращает в список, `→` в письме ничего не делает (открывает письмо только в списке). Клиент только читает, текст письма изменить нельзя.

В списке: `N` — не прочитано, `!` — помечено, `r` — отвечено, `T` — в корзине, `D` — черновик.
Ввод строки (поиск, путь): `Enter` — применить, `Esc` — отмена. Если сохраняемый файл уже существует, программа откажется его затирать.

### Свои клавиши

Файл `~/.config/maills/keys.conf` (образец — [keys.conf.example](keys.conf.example)):

# клавиша = команда
x = toggle-flagged
Q = none          # снять привязку

Имена клавиш: символ (`a`, `?`, `й`) или `Up Down Left Right Enter Esc Space Tab Backspace PageUp PageDown Home End F1`.
Названия команд — первый столбец таблицы выше (полный список — на экране `?`). Ошибки в конфиге показываются как предупреждения и не мешают запуску.

## Ящик Maildir

Mail/
  new/   новые (не прочитанные) письма
  cur/   письма с флагами в имени:  1699999999.M1P1.host:2,FRS
  tmp/

Флаги `S` (прочитано), `F` (помечено), `R`, `T`, `D` хранятся только в имени файла, буквы по алфавиту; смена флага — атомарный `rename`.
Новое письмо можно «доставить» вручную: положить файл в `new/` и нажать `R`.
